# Models

This directory stores trained model artifacts created by the machine-learning and LLM workflows.

## Directory Structure

```text
models/
├── ml/        Classical ML model and vectorizer artifacts
└── qwen_lora/ Qwen LoRA adapter and training checkpoints
```

## Contents

* `ml/` stores the trained logistic regression, random forest, and XGBoost models, along with the TF-IDF vectorizer.
* `qwen_lora/` stores the fine-tuned Qwen LoRA adapter and its checkpoints.

These files are generated by the training workflows and are loaded during evaluation or inference.
